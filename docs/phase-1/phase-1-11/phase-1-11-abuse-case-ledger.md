## Concurrency race summary

The mandatory concurrency set for P1-11: invoice-numbering race (strict sequence, no
duplicates, no consumed number on abort), duplicate-issue race (one live invoice per WO),
allocation race (×5 — total never exceeds receipt or invoice open), concurrent-reversal
race (row-lock original + sum prior reversals), and double-custody-release race (locked
delivery + `uq_custody_history_released` backstop). Each produces exactly one correct
effect; the loser raises a deterministic `23505`/`23514`.
