## 2. How to read these tables

| column         | what it holds                                                                                                                                                                                                                                                                         |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Task**       | The canonical id and name from `canonical-plan.md` §5. The `P1-27-` prefix is dropped inside the tables and is part of every id.                                                                                                                                                      |
| **Operations** | The operation ids the shipped web code actually calls, with the permission each route registers. An operation a document attributes to a task but that no web file calls is **not** listed — see §9.                                                                                  |
| **Output**     | The files the task produced. Frontend paths are relative to `apps/web/src/`.                                                                                                                                                                                                          |
| **Proof**      | A test file and the **case within it**, quoted from the test's own title; where a `describe` is quoted instead of an `it`, it is labelled as one. Where a task's only proof is a gate, the gate is named together with what it refuses. "Covered" is not a proof and does not appear. |

Test paths are relative to `apps/web/tests/` unless a `tests/ci/` prefix is
given, in which case they are relative to the repository root.

Every case count in this document was measured by running the file on this
branch — `develop` `19f370b982ebd7750612239154311f0036e5c34e`. Where a count
disagrees with `task-register.md`, the measured number is used and the
disagreement is recorded in §11.
