## 2. Mentioned, and defined — the distinction the rest of this document rests on

| term          | what it means here                                                                                                                               |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Mentioned** | The identifier appears somewhere in `docs/`, usually inside a sentence that assumes the reader already knows what it means.                      |
| **Defined**   | There is an entry naming the risk, with a **trigger** (the condition that would realise it), a **mitigation** (what holds it), and an **owner**. |

A mention cannot be dispositioned. "Is `RSK-31` mitigated?" has no honest answer
when nothing in the repository says what `RSK-31` is, and answering it anyway is
how a gate record comes to read as complete while proving nothing.

### 6.2 `P1-27-R-02` — a class name that resolves to nothing

|                       |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Trigger**           | Source names a styling identifier that the styling system does not know, and the styling system says nothing about it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **Evidence**          | Seven Tailwind colour names — `brand-primary`, `on-brand`, `status-danger`, `status-success`, `status-warning`, `link`, `paper` — were used across **fourteen** components and registered in the theme in none. **51 utilities had no rule behind them.** Every primary button on the CRM and Vehicle screens rendered with no fill, every error message was not red, every success message was not green, and the printed document had no page colour. The Owner did not report this as a defect; the remediation found it. | **Why it hid**        | Tailwind emits CSS only for utilities it recognises. An unrecognised class is not an error, not a warning and not a build failure — it is a name with no rule behind it.
