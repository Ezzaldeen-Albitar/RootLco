## Purpose

This register lists every decision that remains open at the time the Phase 1-1 (Source-of-Truth Validation and Development Readiness) closure gate is assessed. Each entry records what is undecided, who decides it, and — honestly and specifically — whether it blocks the Phase 1-1 gate itself or only later phases. Canonical Word documents remain the source of truth and live outside the repository (see `docs/governance/canonical-documents.md`); this register does not replace them.

## Blocking classification

| Classification                  | Meaning                                                                                                                                          |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Blocks Phase 1-1 gate**       | The gate cannot honestly be declared passed while this remains unresolved or unevidenced.                                                        |
| **Conditional / gate-relevant** | Does not by itself prevent closure, but must be recorded as a risk, exception, or conditional item in the gate decision, with a named follow-up. |
| **Blocks later phases only**    | Phase 1-1 can close; the decision must land before the named later phase starts.                                                                 |
| **Not blocking**                | Open by design; tracked, with no phase currently waiting on it.                                                                                  |
