## Local networking note: two hostnames, one Supabase

The local Supabase stack is reached through two hostnames depending on where the caller runs, and both point at the same stack:

- **From the host browser and host-native tooling:** `127.0.0.1:54321` (API), with the database on `54322` and Studio on `54323`.
- **From inside the app container:** `host.docker.internal:54321`, exposed through the compose `extra_hosts: host.docker.internal:host-gateway` entry and recorded as `SUPABASE_INTERNAL_URL`. This variable is documented but unused in Phase 1-1.

Supabase is deliberately not part of the compose file; it runs as the official CLI stack only (ADR-003 and ADR-007).

## What Local proves, and what it cannot prove

The Local environment proves that the committed repository is coherent and runnable end to end on a developer machine: the application builds and serves under Docker as a non-root user, the quality gate passes with measured exit codes, the Supabase CLI stack answers real queries against PostgreSQL 17.6, secrets stay out of Git, and the developer feedback loop (hot reload of approximately 6 seconds) is workable. It proves readiness to begin implementation in Phase 1-2.

It cannot prove production behaviour, scale, or hosting. No load, latency, availability, backup, data-residency, or cost characteristic of any hosted environment can be inferred from a single-machine Docker Desktop setup on Windows, and Docker itself does not automatically improve performance — Windows bind mounts are slower, and the named volumes exist precisely to keep local performance acceptable. Any statement about how the platform will behave on a provider, in a region, or on a deployment platform would be a fabrication until the owners approve one and a provisioned environment produces its own evidence.

## Promotion rule

An environment moves out of "Planned — not provisioned" only when both of the following are true:

1. The product owners jointly approve the provider, region, and deployment platform for that environment (currently all Proposed / Open under ADR-012).
2. The applicable phase gate for provisioning that environment has been passed and evidenced.

Until then, this matrix is the honest and complete description of the environment landscape.
