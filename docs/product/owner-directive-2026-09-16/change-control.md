## Rules

- A row closes only with a dated note naming the merged pull request that closed it. The note is
  added to this file in the same change that flips the status.
- No row is closed by a plan. A plan to fix a finding leaves the row open; the merge closes it.
- `fixed in this branch (hosted result pending)` means the code change is committed on the named
  branch and the hosted result for that branch has not been read yet. It is not a closed row.
